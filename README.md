# 💰 LedgerSight | E-commerce Analytics

## 📊 Project Overview

**LedgerSight** is an **Excel-based E-commerce Analytics project** built using the Olist dataset to analyze business performance, revenue, orders, payments, profitability, and delivery operations.

The project combines **data analysis, calculated business metrics, PivotTables, KPIs, and forecasting** into an interactive Excel dashboard designed to provide a clear view of overall e-commerce performance.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze total revenue and order performance.
* Track overall order volume.
* Measure profitability and gross margin.
* Analyze payment methods and payment behavior.
* Identify late deliveries and delivery delays.
* Monitor order status.
* Compare actual revenue with expected revenue.
* Forecast future revenue.
* Reconcile payments with order values.
* Build an interactive business dashboard.

## 🗂️ Dataset

The project is based on the **Olist e-commerce dataset**.

The workbook contains several analytical datasets, including:

* `olist_orders_dataset`
* `olist_order_items_dataset`
* `olist_order_payments_dataset`

The orders dataset contains approximately **101K order records**, while the supporting datasets provide item-level and payment-level information.

## 🔮 Revenue Forecasting

One of the key analytical components of **LedgerSight** is revenue forecasting.

The project uses Excel's **FORECAST.ETS** functionality to estimate future monthly revenue based on historical revenue trends.

The forecast section compares:

```text
Historical Revenue
        ↓
Revenue Trend
        ↓
Forecast Model
        ↓
Expected Revenue
        ↓
Actual vs. Expected
        ↓
Reconciliation
```
